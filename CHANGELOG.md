# Changelog

## v0.1.0-alpha — first public release (draft, unpublished)

Initial Italian-only Linux desktop Alpha, prepared from the internal alpha.5 snapshot.

- Groq AI interpretation and local Whisper Small voice transcription.
- Desktop interface, tray, launcher and desktop-dependent shortcuts.
- Applications, constrained package installation and system updates.
- Nobara updates through `nobara-sync cli`.
- Multimedia, browser searches, YouTube, files, clipboard and reminders.
- Screenshot backends, GPU Screen Recorder and OBS recording/replay integration.
- Reinstalling the launcher updates stale paths and refreshes the KDE menu cache.
- English discovery README and retained Italian user guide.

Practical tests reported on Nobara KDE, Ubuntu GNOME and Linux Mint Cinnamon.
Fedora and Arch are not fully verified. This is not a claim of exhaustive testing.

No English app support, local language model or arbitrary root operations added.
GNU GPLv3-only was selected by the author. Publication date remains pending.
Asset redistribution rights still require confirmation; see docs/THIRD_PARTY.md.
