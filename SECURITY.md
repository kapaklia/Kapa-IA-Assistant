# Security and privacy

This early Alpha is not a sandbox. Review requests that can affect desktop files
or applications. Administrative actions are limited to package installation and
system updates, with confirmation in a separate terminal.

Do not post API keys, OBS passwords, conversation logs, private file contents or
voice recordings in issues. Revoke any leaked credential at its provider; merely
removing it from the latest file or adding `.gitignore` does not erase Git history.

No private security contact has been configured yet. Before the public launch,
the maintainer should enable GitHub private vulnerability reporting. Do not publish
exploit details or sensitive data in a public issue while that channel is unavailable.
There is no guaranteed response time or supported stable release yet.
